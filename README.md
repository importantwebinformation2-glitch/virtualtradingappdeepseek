# 📈 Virtual Trading Pro

A feature-rich virtual trading app with real-time prices, WebSocket updates, charts, and virtual money.

## Features
- ✅ Real-time stock prices (WebSocket + REST)
- ✅ Equity, Intraday (5x), and Options trading
- ✅ Stop-loss and Take-profit orders
- ✅ Interactive charts (1D, 5D, 1M)
- ✅ Virtual balance management
- ✅ P&L tracking
- ✅ Dark mode
- ✅ Mobile responsive
- ✅ Export transactions to CSV

## Tech Stack
- React + Vite
- Tailwind CSS
- Yahoo Finance API
- WebSocket
- Recharts
